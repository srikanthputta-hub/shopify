# Shopify Store — Trending Products, India

Planning and catalog repo for a Shopify store selling trending, affordable lifestyle products to shoppers in India.

- **Live store:** `ryus35-11.myshopify.com` (Basic plan, currency INR, timezone IST)
- **Working brand name:** TrendNest (placeholder, not final; trademark/domain not yet checked)
- **Other name candidates:** Daily Dwell, KitchEase, GadgetGlee, ValueVista, CozyCraft

Shopify holds the live store. This repo holds the plan, catalog data, and launch checklist so changes stay versioned.

## Layout

- `catalog/collections.md` — collection structure
- `docs/launch-checklist.md` — India-specific launch steps

All data is for planning; nothing here is a published product until it is created in Shopify.
