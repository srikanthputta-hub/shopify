# Launch checklist (India)

- [ ] Final brand name and domain (.in / .com), trademark check
- [ ] Rename store from "My Store"; set store email and address
- [ ] GST registration and tax settings (prices tax-inclusive in INR)
- [ ] Payments: Razorpay / UPI / cards; decide on Cash on Delivery
- [ ] Shipping: carrier or aggregator, rates, pincode serviceability
- [ ] Policies: refund, shipping, privacy, terms (required by Indian consumer rules)
- [ ] Theme selection and customisation in Shopify admin
- [ ] Draft products reviewed, then activated
- [ ] Test order end to end before going live
